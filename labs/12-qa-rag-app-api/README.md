# Lab 12 · Build a QA-based RAG App using the Bedrock API

**Track:** Embeddings & RAG · **Mode:** API · **Services:** Bedrock Knowledge Bases, Amazon Bedrock

## Objective
Built a question-answering app with the Retrieve and RetrieveAndGenerate APIs, surfacing sources with every answer.

## What I did
- Called RetrieveAndGenerate with a Knowledge Base
- Displayed citations and source locations
- Tuned the number of retrieved results
