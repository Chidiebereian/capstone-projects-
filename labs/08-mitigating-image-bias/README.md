# Lab 08 · Mitigating Image Bias with Effective Prompts

**Track:** Prompting & Responsible AI · **Mode:** Console · **Services:** Amazon Bedrock, Titan Image Generator

## Objective
Identified demographic bias in generated images and reduced it with explicit, inclusive prompt wording and negative prompts.

## What I did
- Audited image outputs for representational bias
- Applied inclusive and negative prompting
- Documented a responsible-AI prompt checklist
